# Loja Natalina - Website
Uma experiência digital dedicada ao universo da decoração natalina. A NOËL combina elegância, sofisticação e funcionalidade em uma loja virtual desenvolvida com tecnologias web fundamentais.

---

## Sobre o projeto

A **Loja Natalina - Website** é uma loja virtual de produtos natalinos, desenvolvida com foco em uma identidade visual sofisticada e uma experiência de navegação intuitiva.

O projeto busca transmitir a atmosfera do Natal por meio de uma estética inspirada em marcas europeias de decoração, utilizando tons de verde pinheiro, creme, marfim e dourado.

## Páginas

O site conta com cinco páginas principais:

- **Home:** apresentação da marca, banner principal e produtos em destaque.
- **Produtos:** catálogo de produtos com organização por categorias.
- **Coleções:** apresentação de coleções natalinas por estilos e temas.
- **Sobre:** história, identidade e proposta da NOËL.
- **Contato:** formulário para comunicação com a loja.

## Funcionalidades

- Navegação entre páginas.
- Catálogo de produtos gerado dinamicamente com JavaScript.
- Organização e filtragem por categorias.
- Pesquisa de produtos por nome.
- Carrinho de compras com adição e remoção de itens.
- Armazenamento de dados utilizando LocalStorage.
- Carrossel de imagens.
- Efeito Parallax.
- Efeitos sonoros com opção de ativação e desativação.
- Validação de formulário de contato.
- Layout responsivo para computadores, tablets e celulares.
- Animações e transições CSS.

## Tecnologias utilizadas

| Tecnologia | Utilização |
|---|---|
| HTML5 | Estrutura das páginas |
| CSS3 | Estilização, animações e responsividade |
| JavaScript | Funcionalidades e interatividade |
| LocalStorage | Persistência do carrinho |

O projeto utiliza JavaScript puro (Vanilla JS), sem frameworks ou bibliotecas externas de interface.

## Como executar

1. Faça o download ou clone este repositório.
2. Extraia os arquivos, caso necessário.
3. Abra o arquivo `index.html` no navegador.
4. Navegue pelas páginas e explore as funcionalidades.

Não é necessário instalar dependências ou configurar frameworks.
